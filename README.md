# 🧾 Organizador Financeiro de Recibos

Aplicação web moderna desenvolvida em **HTML5**, **CSS3** e **JavaScript**, com integração da **Puter.js (IA)** para leitura automática e organização inteligente de recibos e comprovantes financeiros.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página web.
* **CSS3:** Estilização responsiva, layout moderno e interface amigável.
* **JavaScript (ES6+):** Lógica da aplicação, manipulação do DOM e integração com a IA.
* **Puter.js (Puter.AI):** Biblioteca para processamento e leitura automática de dados com IA.
* **Git e GitHub:** Versionamento de código e publicação.

---

## ⚙️ Funcionalidades

* **Envio de Recibos:** Upload e carregamento simples de comprovantes e recibos.
* **Leitura Inteligente via IA:** Extração automática de dados como valor, estabelecimento e data.
* **Organização Financeira:** Categorização e estruturação dos comprovantes cadastrados.
* **Visualização Limpa:** Exibição organizada dos comprovantes processados na tela.

---

## 🧠 Conceitos Aplicados

* **Manipulação do DOM:** Alteração e atualização dinâmica dos elementos da página.
* **Programação Assíncrona (Async/Await):** Requisições assíncronas para integração com a Puter.js.
* **Tratamento de Eventos (Event Listeners):** Captura de interações do usuário (cliques e formulários).
* **Design Responsivo:** Visual moderno e adaptável para diferentes dispositivos.

---
